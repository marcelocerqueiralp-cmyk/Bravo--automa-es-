# Bravo CRM Consignado

CRM completo para crédito consignado INSS/GOV Bahia.

## Deploy no Vercel

1. Acesse https://vercel.com/new
2. Importe este repositório do GitHub
3. Configurações automáticas (Next.js detectado)
4. Clique Deploy

## Estrutura

- `/` → CRM completo (dashboard, contatos, funil, higienização...)
- `/refin` → Simulador de refinanciamento + Agente Ben
